# v6 frontend design brief

The contract for everything in `frontend/`. Goal: **one product** that feels like
the NiceGUI desktop app on a PC and like the v5 web companion on a phone, but more
consistent, more mature and clearly professional (think Linear / Stripe dashboard
quality, not a hobby page).

## Principles

1. **One design system, two densities.** The same components, tokens and copy on
   every screen size; layout and density adapt, features never disappear on mobile.
2. **Numbers first.** Tabular figures (`font-variant-numeric: tabular-nums`) for
   every amount, right-aligned in tables, consistent sign/colour rules
   (gains `--color-pos`, losses `--color-neg`; never red/green).
3. **Calm surfaces.** Cards on a subtle background, 1px borders, soft shadows, no
   heavy gradients except the existing faint accent glow behind the page.
4. **Fast and honest.** Instant open from the persisted query cache; every view shows
   its data freshness ("Live · 14:32 ET", "Closed · prices as of Fri 22:00").
   Skeleton loaders, never spinners over blank pages. Errors are inline and calm.
5. **Accessible.** Radix primitives for dialog, dropdown, tooltip, tabs, toast,
   switch, select; visible focus rings; WCAG AA contrast in both themes;
   keyboard shortcuts on desktop (`g o` overview, `g h` holdings, `/` search,
   `?` shortcut help).
6. **Weak client.** No business maths in the frontend; formatting only.

## Tokens (`src/styles/tokens.scss`)

Port the v5 palette from `web/src/styles.css` (`:root` and dark blocks) into
namespaced custom properties: `--color-fg`, `--color-muted`, `--color-faint`,
`--color-accent`, `--color-bg`, `--color-surface` (card), `--color-surface-2`
(pill / hover), `--color-border`, `--color-pos`, `--color-neg`, `--color-pos-soft`,
`--color-neg-soft`, `--color-warn`; plus `--space-1..8` (4px scale),
`--radius-sm|md|lg` (8/12/18), `--shadow-1|2`, `--font-sans` (Inter variable),
`--font-size-xs..3xl`, `--sidebar-width`, `--topbar-height`, `--tabbar-height`,
`--z-*`. Theme via `[data-theme="dark"|"light"]` on `<html>`, defaulting to
`prefers-color-scheme`. Chart series colours as tokens too (`--chart-1..6`).

## Layout shell (`components/AppShell`)

- **Desktop ≥ 1024px** (NiceGUI feel): fixed left sidebar (`--sidebar-width` 240px,
  collapsible to a 64px icon rail) with grouped navigation; top bar with page title,
  freshness indicator, EUR/USD segmented toggle, refresh button, theme toggle, user
  menu. Content max-width 1440px, 12-column grid, dense tables, multi-column cards.
- **Tablet 640–1023px:** icon rail sidebar + same top bar.
- **Phone < 640px** (v5 web companion feel): compact top bar (title + freshness +
  currency toggle), **bottom tab bar** with 4 primary tabs (Overview, Holdings,
  Activity, Periods) + "More" sheet for the rest; cards stack, tables become
  list rows, large tap targets (≥ 44px), safe-area insets, pull-to-refresh.

Navigation groups (desktop sidebar):
- **Portfolio:** Overview, Holdings, Periods (monthly/yearly tabs), Activity
  (deposits + dividends), Risk & analytics, Projection & calculator
- **Manage:** Transactions, Import, Currency conversions, Allocations
- **System:** Data health (diagnostics), Settings, Help

## Component kit (`components/`)

`AppShell`, `Sidebar`, `TopBar`, `TabBar`, `PageHeader`, `Card`, `KpiTile`
(label, value, delta, sparkline slot), `DeltaBadge`, `Money` (amount + currency,
sign colouring), `Percent`, `DataTable` (sortable, sticky header, right-aligned
numbers, collapses to list rows on phone), `SegmentedControl`, `Button`
(primary/secondary/ghost/danger, sizes), `IconButton`, `Input`, `Select`, `Field`
(label + hint + error), `Dialog`, `Sheet` (mobile bottom sheet), `Menu`,
`Tooltip`, `Toast`, `Skeleton`, `EmptyState`, `ErrorState`, `Freshness`,
`Chart` (wrapping the v5 `web/src/chart.ts` SVG line chart as a React component:
range tabs 1D/1W/1M/1Y/ALL, hover crosshair + tooltip, currency line),
`Treemap`/`AllocationBar`, `Icon` (one icon set: `lucide-react`).

## Pages (`pages/`)

Login (password + "Sign in with passkey"), Overview (KPI row incl. currency-effect
split, value chart, allocation, top movers), Holdings, Periods, Activity, Risk,
Calculator/Projection, Transactions (list + manual add/edit), Import (upload →
preview → confirm), CurrencyConversions, Allocations (+ rebalance plan), Settings
(currency, theme, timezone, passkeys, backup download), Diagnostics, Onboarding,
NotFound.

## Data layer (`lib/`)

- `lib/api.ts`: typed `fetch` wrapper (`credentials: 'same-origin'`, JSON, throws
  `ApiError` with status), types from `lib/api-types.ts` (generated by
  `openapi-typescript` from the backend's `openapi.json`; never hand-edited).
- `lib/queries.ts`: TanStack Query hooks per endpoint; query keys include `ccy`.
  `PersistQueryClientProvider` with localStorage persister for instant/offline open.
- `lib/live.ts`: `EventSource('/api/stream')`, updates the query cache on ticks.
- `lib/format.ts`: `Intl.NumberFormat` money/percent/date helpers (display only).
- A 401 from any call routes to `/login`.

## Auth endpoints the frontend uses

`POST /api/auth/login {password}` → 204 + cookie · `POST /api/auth/logout` ·
`GET /api/auth/me` → `{authenticated, passkeys: n}` · `POST /api/auth/passkey/login/options`
→ WebAuthn request options JSON · `POST /api/auth/passkey/login/verify` ·
`POST /api/auth/passkey/register/options` · `POST /api/auth/passkey/register/verify`
· `GET /api/auth/passkeys` · `DELETE /api/auth/passkeys/{id}`.
Use `@simplewebauthn/browser` on the client.

## Kit reference (as built in F1, commit b0565ac)

Icons: use `lucide-react` directly (no Icon wrapper). TypeScript is pinned to ~5.9
(openapi-typescript compatibility). Nav items live in `lib/nav.ts`; top-bar page
titles derive from it.

Shell hooks: `useShellStatus(status, label, onRefresh, refreshing)` (`lib/shell.tsx`)
publishes a page's freshness + refresh action to the top bar · `usePrefs()` →
currency/theme · `useToast().toast({title, description, tone})` · endpoint hook
pattern documented in `lib/queries.ts` (`useAuthMe` exists). Shortcuts: `g`+letter,
`/` focuses `[data-search]`, `?` help.
